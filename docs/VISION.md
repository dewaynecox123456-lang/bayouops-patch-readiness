# Vision

BayouOps Patch Readiness provides clean, fast, read-only operational visibility for patch windows.

It is designed for administrators who need quick answers before, during, or after maintenance windows.

## Core Principle

Visibility, not control.

The tool should never automatically patch, reboot, fail over, or modify production systems.

## Future Features

- HTML report
- SQL pair warning detection
- LOB summary
- owner/contact summary
- missing metadata warnings
- CAB-ready export
